# MoveUni

### Entenda nossa proposta

Criar um software que encontre estudantes que pratiquem esportes e marcar jogos com eles, onde cada estudante marca sua disponibilidade e os esportes que joga, com isso, se fechar 2 times para um jogo, ou no caso da corrida, fechar um grupo para correr, ele marca aquele horário, escolher a atividade com mais pessoas caso tenham 2 possíveis no mesmo horário.
Seria feito também um sistema de nível (ex: iniciante, intermediário, avançado) para separar e se possível marcar com pessoas do mesmo nível, se não, deixaria claro o nível "médio" da partida para deixar claro para todos, além de que deixaria marcado no calendário, para caso alguém quiser comparecer em um evento já existente poder apenas se incluir nesse horário.
